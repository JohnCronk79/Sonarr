# Supporting evidence

These files contain the summaries and trace evidence used for the performance results.

- `work-normalized-performance.csv` contains the measured work-normalized comparisons.
- `balanced-retry-results.json` and `balanced-retry-scenario-summary.csv` contain the 4,000-episode balanced workload results.
- `cache-event-replay-results.json` contains the accelerated 4,248-episode cache lifecycle replay results.
- `gap-fill-instrumentation.jsonl` contains the cache and #8884 instrumentation trace.
- `gap-fill-replay-events.jsonl` contains the matching replay events.
- `gap-fill-final-status.json` and `gap-fill-final-system-status.json` contain the completed retry-heavy validation state.
- `test6-final-summary.json` and `test6-final-system-status.json` contain the 1,011-episode run summary and cache state.
- `targeted-211-final-summary.json` and `targeted-211-final-system-status.json` contain the targeted retry and cache validation results.

`SHA256SUMS.txt` records a checksum for every evidence file.
